# Ambiarta Service

This repository is the public distribution destination for the **Ambiarta
Service** Supervisor app. It will run the processing service alongside Home
Assistant. Install the [Ambiarta-HA integration](https://github.com/PlisskenGx/Ambiarta-HA)
for the **Ambiarta** sidebar, Settings, and central support.

**Publication status:** The app image and installable Supervisor repository
metadata have not been published. Do not add this URL as a Home Assistant app
repository yet. A local app candidate `0.1.0` was tested in a disposable
development Supervisor environment; a registry-backed installation on Home
Assistant OS remains a release gate.

The app and the [separate-device distribution](https://github.com/PlisskenGx/Ambiarta-Service-Device)
will package the same processing engine. This repository will receive generated
app metadata and release documentation after the shared engine, images, and
registry visibility are validated. It is not another engine source tree.

See [Ambiarta-HA](https://github.com/PlisskenGx/Ambiarta-HA) for documentation
and [support](https://github.com/PlisskenGx/Ambiarta-HA/issues). License terms
are in [LICENSE](LICENSE).
